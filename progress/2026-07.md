### LC 2812 - Find the Safest Path in a Grid (Medium)

**Pattern:** Multi-source BFS + Binary Search + DFS/BFS Reachability

**Approach:**
1. Compute safety grid using multi-source BFS from all thieves simultaneously — each cell stores the minimum Manhattan distance to the nearest thief
2. Binary search on the safeness factor threshold (range: 0 to max safety value)
3. For each threshold, use DFS to check if a path exists from (0,0) to (n-1,n-1) where every cell has safety ≥ threshold

**Key Learning:**
- **Greedy fails for "maximize the minimum" problems:** Initial approach picked the neighbor with the highest safety factor at each step — this makes locally optimal choices that lead to globally suboptimal paths. Traced through example 6 to understand why.
- **Binary search on the answer:** Recognized the monotonicity property — if a path exists with safety ≥ k, then a path exists with safety ≥ k-1. This makes binary search applicable.
- **Multi-source BFS:** Starting BFS from all thieves simultaneously gives the minimum distance to any thief in O(n²), much better than the brute-force O(n² × T) approach.
- **New pattern identified:** "Maximize the minimum" → binary search + feasibility check

**Weaknesses Identified:**
- **Greedy instinct:** Tendency to reach for greedy pathfinding when the problem requires global optimization. Need to ask: "Is the locally optimal choice also globally optimal?"
- **(0,0) not marked as visited in DFS:** Minor correctness gap — the starting cell was never marked visited, causing redundant exploration. Not a wrong-answer bug in practice, but a correctness issue.
- **DFS stack depth:** Using recursion for reachability check could cause stack overflow for large grids (n=400). BFS would be safer.

**Honest Self-Assessment:**
- Started with greedy approach (failed) → pivoted to multi-source BFS + binary search with guidance
- Good progress on understanding WHY greedy fails (traced example 6)
- The "maximize the minimum" → binary search pattern is new — need to internalize this

**Complexity:**
- Time: O(n² log n) — O(n²) for safety grid, O(log n) binary search steps, O(n²) DFS per step
- Space: O(n²) — safety grid and visited array

**Status:** Solved ✓ (with guidance on pattern recognition)
