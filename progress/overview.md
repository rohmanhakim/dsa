- **Prefix Sum** — Three guided applications: LC 3756 (range sum with digit concatenation), LC 3532 (range emptiness for connectivity queries), and LC 3534 (component connectivity via sorted adjacency breaks). Core idea: precompute cumulative values in O(n) to answer range queries in O(1). Two variants learned:
  - **Variant A (range sum):** 1-indexed arrays with sentinel at index 0, query on [l,r] uses `pref[r+1] - pref[l]`. For non-trivial functions, precompute powers of the base.

The `matches` counter optimization tracks how many of the 26 positions match — each add/remove updates exactly one character → O(1) per step. - **Binary Lifting** — First application via LC 3534 (guided). Sparse table for answering "shortest path" queries on sorted array graphs in O(log n). Key template:

### Constraint-Based Algorithm Selection (Reference)
| Constraint Size | Complexity Target | Algorithm Family |
|---|---|---|
| n ≤ 10⁴ | O(n²) | Brute force, nested loops |
| n ≤ 10⁵ | O(n log n) | Sorting, binary search, two pointers |
| n ≤ 10⁶ | O(n) | Sliding window, hash map, BFS/DFS |
| n ≤ 10⁷ | O(n) | Linear scan, monotonic stack |
| n ≤ 10⁸ | O(n log n) | Rare, usually requires optimization tricks |
